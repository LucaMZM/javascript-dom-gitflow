Un laboratori per a aprendre fent

L'objectiu és seleccionar elements del document, modificar-ne el contingut i els atributs, i controlar-ne la presentació. Cada exemple inclou controls, codi i un resultat visible.

Pràctica 1 de Luca Mazmishvili · Sistemes de control de versions

Modificar contingut HTML

Canvia el text d'un element o interpreta una estructura HTML coneguda.

textContent: text literal

Este text canviarà.

// El contingut s'insereix com a text.
const resultat = document.querySelector('#text-result');
resultat.textContent = entrada.value;

Si escrius <strong>hola</strong>, veuràs les etiquetes com a text.

innerHTML: estructura HTML

Encara no hi ha format.
// Plantilla fixa i controlada.
resultat.innerHTML =
  '<strong>Hola, DOM!</strong> Ara amb format.';

innerHTML interpreta etiquetes. No l'utilitzem amb entrades de l'usuari perquè podrien inserir contingut insegur.

Modificar atributs HTML

Els atributs descriuen el comportament i les propietats d'un element.

setAttribute i getAttribute

Guia de JavaScript de MDNLlig l'atribut per veure'n el valor.
// Escriure i llegir un atribut.
enllaç.setAttribute('title', entrada.value);
resultat.textContent = enllaç.getAttribute('title');

Passa el punter sobre l'enllaç per consultar-ne el títol. El destí es manté fix.

Propietats HTML

disabled = true
// Una propietat booleana controla el botó.
botó.disabled = !botó.disabled;
resultat.textContent = 'disabled = ' + botó.disabled;

disabled és una propietat booleana. Un atribut disabled present, encara que diga "false", també desactiva el botó.
